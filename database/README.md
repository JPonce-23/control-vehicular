# Base de Datos - Control Vehicular

Esta carpeta contiene los scripts SQL del Sistema de Control Vehicular.

## Orden de ejecución

1. Ejecutar `01_create_database.sql` desde pgAdmin.
2. Conectarse a la base de datos `control_vehicular`.
3. Ejecutar `02_create_tables.sql`.
4. Y más adelante ejecutar `03_seed_data.sql` para datos iniciales.
