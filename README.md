# Sistema de Control Vehicular PA

Sistema web interno para administrar vehículos, personas autorizadas, salidas, regresos, resguardos y gastos de gasolina.

## Stack utilizado

- Python
- PostgreSQL
- HTML
- CSS
- JavaScript
